실험실 ​

실험실은 라이브러리와 상관없이 프롬프트 하나를 자유롭게 시험하는 곳입니다. 시드를 바꿔 보거나 설정값 하나만 바꿔 가며 결과를 나란히 비교합니다. 결과는 outputs/_lab/<날짜>/에 저장되고 갤러리에도 보입니다.

프롬프트와 생성 설정 ​

  • 프롬프트 / 제외 프롬프트: 직접 적습니다. 태그 자동완성이 됩니다. 긍정 태그 확인 / 제외 태그 확인은 Danbooru에 없는 태그를 알려 줍니다.
  • 생성 설정: 작업 화면과 같은 설정입니다. 프리셋 불러오기로 저장해 둔 생성 프리셋을 불러오고, 현재 설정을 프리셋으로 저장으로 새 프리셋을 만듭니다.

다른 곳에서 넘겨받을 수도 있습니다.

  • 작업 화면 미리보기의 실험실에서 열기
  • 갤러리 이미지 상세의 실험실에서 열기
  • 이미지 도구의 실험실에서 열기, 태그로 실험실 열기

넘겨받으면 위쪽에 가져온 곳이 표시됩니다.

시드 비교 ​

시드 수만큼 시드를 바꿔 생성합니다. 같은 프롬프트가 얼마나 안정적으로 나오는지 볼 때 씁니다.

값 비교 ​

바꿔 볼 값에서 항목 하나를 고르고 값 목록에 비교할 값을 쉼표로 적습니다.

항목값 예
CFG3, 4.5, 6
Steps20, 28, 36
샘플러 · 스케줄러비우면 목록 전체
CLIP skip (SDXL)1, 2
LoRA 강도0.4, 0.7, 1.0

시드 수 × 값 개수만큼 생성됩니다(화면에 시드 2개 × 값 3개 = 6장처럼 표시).

결과 비교 ​

결과에서 두 장을 골라 기준과 비교로 놓고 봅니다.

  • 나란히: 두 장을 옆에 놓습니다.
  • 슬라이더: 한 장 위에 다른 장을 겹치고 경계를 끌어 차이를 봅니다.
  • 기준↔비교 바꾸기, 비교 이미지 설정 불러오기(마음에 든 쪽의 설정을 폼으로 가져옴)를 쓸 수 있습니다.
