# LoRA 학습

**LoRA** 메뉴는 캐릭터별로 통과한 이미지를 골라 LoRA를 학습하고, 결과를 등록해 그 캐릭터를 생성할
때 자동으로 적용합니다. 학습에는 [anima_lora](https://github.com/sorryhyun/anima_lora)를 씁니다.
설치는 [README](https://github.com/kiritype/asset-studio#lora-training)를 보세요.

왼쪽에서 작품과 캐릭터를 고르면 **데이터셋**, **학습**, **LoRA 목록** 탭이 나옵니다.

## 1. 데이터셋 만들기

![데이터셋 이미지 고르기](/shots/16-lora-character.webp)

1. **의상 세트**를 고릅니다. 데이터셋은 의상 세트 하나 단위로 만듭니다.
2. **이름**과 **캐릭터 트리거**를 적습니다. 트리거는 이 캐릭터만의 단어(예: `lyra_vance`)로, 캡션 맨
   앞쪽에 들어가고 생성할 때도 자동으로 붙습니다. 의상까지 따로 배우게 하려면 **의상 트리거**도 적습니다.
3. 학습할 이미지를 고릅니다. 그 캐릭터·의상의 이미지가 모두 보이고, 갤러리에서 판정한 결과가
   **채택**·**통과**·**실패**로 표시됩니다. 하나씩 체크하거나 버튼으로 한 번에 고릅니다.
   - **채택 이미지만**: 감정마다 채택된 한 장씩.
   - **통과 이미지 전부**: 통과한 이미지 모두.
   - **선택 해제**: 모두 해제.
4. **데이터셋 만들기**를 누릅니다.

### 캡션

데이터셋을 만들면 이미지마다 캡션이 자동으로 생깁니다. 트리거, 구도, 감정 태그는 남기고 외형·의상
태그는 뺍니다. 외형과 의상을 트리거 단어가 배우게 하기 위해서입니다.

![자동 캡션](/shots/19-lora-captions.webp)

캡션은 직접 고치고 **고친 캡션 저장**으로 저장할 수 있습니다. **자동 캡션 다시 만들기**는 처음
상태로 되돌립니다.

### 좋은 데이터셋

- **이미지 수**: 25장 이상을 권합니다. 15장 정도로는 구도가 흔들릴 수 있습니다.
- **정사각형 이미지**(예: 1536×1536)를 권합니다. 한쪽 비율만 있으면 그 비율의 구도까지 배웁니다.
- **다양한 표정과 동작**: 같은 자세만 있으면 그 자세가 굳어집니다.
- 학습한 이미지와 같은 계열의 모델로 생성할 때 결과가 가장 좋습니다.

## 2. 학습

![학습 설정](/shots/20-lora-train-form.webp)

| 항목        | 설명                                                                      |
| ----------- | ------------------------------------------------------------------------- |
| 데이터셋    | 1단계에서 만든 데이터셋.                                                  |
| 방식        | **T-LoRA**(기본, dim 32, alpha 32) 또는 일반 **LoRA**(dim 32, alpha 128). |
| 베이스 모델 | **공식 Anima base**(기본) 또는 **생성 모델**(설정에 적은 Anima 파인튜닝). |
| 에폭        | 데이터셋을 몇 번 반복해 학습할지. 기본 40.                                |
| 저장 간격   | 이 에폭마다 파일을 남깁니다. 기본 10이면 e10, e20, e30, e40이 생깁니다.   |
| 학습률      | 기본 1e-4.                                                                |

**학습 시작**을 누르면 전처리(이미지 크기 맞춤, 캡션 인코딩) 뒤 학습이 진행되고, **학습 기록**에
진행률이 보입니다. 학습하는 동안에는 새 이미지 생성이 멈추고, 대기 중이던 작업은 학습이 끝난 뒤
이어집니다. 학습 로그는 `logs/lora/<학습 이름>/trainer.log`에 있습니다.

![학습 완료](/shots/23-lora-training-done.webp)

## 3. 등록과 자동 적용

학습이 끝나면 저장된 에폭마다 **eN 등록** 버튼이 생깁니다. 마음에 드는 에폭을 등록하면 **LoRA 목록**
탭에 나옵니다.

![LoRA 목록](/shots/25-lora-list.webp)

| 항목      | 설명                                                                        |
| --------- | --------------------------------------------------------------------------- |
| 자동 적용 | 켜면 작업 화면에서 이 캐릭터를 생성할 때 LoRA와 트리거가 저절로 들어갑니다. |
| 적용 대상 | 이 캐릭터 전체 또는 특정 의상 세트.                                         |
| 범위      | 캐릭터 전용 또는 전역.                                                      |
| 강도      | LoRA 강도. 구도가 흐트러지면 낮춰 보세요.                                   |
| 모델 계열 | 이 LoRA를 쓸 모델 계열.                                                     |

캐릭터·의상·모델 계열마다 자동 적용은 하나만 켤 수 있습니다. 작업 화면의 **등록된 LoRA 자동 적용**을
끄면 그 등록에서만 빼고 생성합니다. 적용 여부는 작업 화면 미리보기의 "자동 LoRA" 표시로 확인합니다.
