# 시작하기

Asset Studio는 내 PC의 [ComfyUI](https://github.com/comfyanonymous/ComfyUI)에 붙어서 동작하는 웹
앱입니다. 캐릭터의 외형·의상·표정을 조각으로 나눠 두고, 필요한 조합을 한 번에 생성해 검수한 뒤,
통과한 이미지로 그 캐릭터의 LoRA를 학습합니다.

이 가이드는 설치를 마친 다음부터 화면을 따라가며 설명합니다. 설치 방법과 필요한 모델·노드 목록은
[README](https://github.com/kiritype/asset-studio#readme)를 보세요.

## 전체 흐름

```
프롬프트 라이브러리 → 이미지 생성 → 갤러리에서 검수 → LoRA 학습 → LoRA를 켜고 다시 생성
                                        ↘ 이미지 도구(프롬프트 형식·태그·인페인트·배경 투명화·가림 처리)
```

| 메뉴          | 하는 일                                                                                      |
| ------------- | -------------------------------------------------------------------------------------------- |
| 프롬프트 수정 | 작품·캐릭터·의상·감정 같은 프롬프트 조각을 만들고 고칩니다.                                  |
| 작업          | 캐릭터 × 의상 × 감정 × 장수를 골라 대기열에 넣습니다.                                        |
| 갤러리        | 생성한 이미지를 보고 통과/실패로 검수합니다.                                                 |
| 이미지 도구   | 프롬프트 형식 변환, 메타데이터 읽기, 태그 분석, 인페인트, 배경 투명화, 가림 처리, WebP 변환. |
| LoRA          | 통과한 이미지로 데이터셋을 만들고 학습해 등록합니다.                                         |
| 생성·비교     | 한 장을 만들거나 시드·설정·작가 후보를 바꿔 결과를 비교합니다.                               |
| 설정          | 언어·테마, ComfyUI 연결, LoRA 학습, GPU 사용 조건.                                           |

화면 오른쪽 위에는 ComfyUI 연결 상태와 대기열 버튼이 늘 보입니다.

## 실행

`launch.bat`을 실행하면 브라우저에서 http://127.0.0.1:8195 가 열립니다. 생성과 이미지 도구를
쓰려면 ComfyUI가 켜져 있어야 합니다(기본 주소 http://127.0.0.1:8188).

처음 열면 라이브러리가 비어 있습니다.

![빈 프롬프트 라이브러리](/shots/01-prompts-empty.webp)

## 샘플 작품으로 시작하기

**프롬프트 수정** 화면 오른쪽 위의 **샘플 가져오기**를 누르면 예시 작품 "Starlight Academy"가
만들어집니다. 학생 두 명(Lyra Vance, Kai Rowan), 교복과 마법사 로브, 감정 다섯 가지, 구도 두 가지가
들어 있어 바로 생성해 볼 수 있습니다.

![샘플 가져오기 완료](/shots/02-sample-imported.webp)

샘플에는 생성 설정(모델·샘플러)이 들어 있지 않습니다. 처음 생성할 때 [이미지 생성](./generate)의
**생성 설정**에서 모델을 고르세요.
