# 설정

모든 설정은 **설정** 화면에서 바꾸고 서버의 `data/settings/`에 저장됩니다. 그래서 같은 PC의 어느
브라우저로 열어도 같은 설정이 보입니다.

![설정](/shots/09-settings.webp)

## 일반

- **언어**: 한국어, English, 日本語, 简体中文. "브라우저 언어 따르기"가 기본입니다.
- **테마**: 라이트, 다크, 시스템 설정 따르기.
- **Danbooru 태그 자동완성**: 프롬프트 입력란의 자동완성을 켜고 끕니다.

## 연결 상태 · ComfyUI 연결 정보

- **연결 상태**: ComfyUI 버전, Python, GPU, 실행·대기 중인 작업 수를 보여 줍니다.
- **로컬 ComfyUI 주소**: 기본 `http://127.0.0.1:8188`.
- **자동으로 찾기**: 이 PC의 ComfyUI(실행 중인 것, Stability Matrix, 포터블, git 설치)를 찾아 보여
  줍니다. **이 설치 사용**을 누르면 입력란이 채워지고, 확인한 뒤 **설정 저장**을 누르면 됩니다.
- **ComfyUI 폴더**와 **Python 실행 파일**을 적으면 이 화면에서 ComfyUI를 **시작**·**종료**·**재시작**할
  수 있습니다. 생성 중이면 현재 작업이 끝난 뒤에 종료·재시작합니다. 다른 곳에서 켠 ComfyUI는 "외부
  프로세스"로 표시되고 여기서 끌 수 없습니다.

## Danbooru 태그 데이터

태그 자동완성과 태그 확인에 쓰는 태그 파일의 위치입니다. ComfyUI-EasyUseAnima가 설치되어 있으면
저절로 찾습니다.

## LoRA 학습

학습 도구(anima_lora) 폴더와 그 Python, 학습한 LoRA를 복사할 폴더, 학습에 쓸 모델 파일(공식 Anima
base, 생성 모델)을 적습니다. 경로마다 파일을 찾았는지 표시됩니다. 학습 도구 설치는
[README의 LoRA 학습](https://github.com/kiritype/asset-studio#lora-training)을 보세요.

LoRA 저장 폴더는 **ComfyUI에서 찾기**로 ComfyUI가 쓰는 LoRA 폴더를 채울 수 있습니다(`anima` 하위
폴더가 있으면 그곳).

ComfyUI 커스텀 노드는 `tools/install_comfy_nodes.py`로 확인한 버전을 설치합니다. 자세한 내용은
[README의 설치](https://github.com/kiritype/asset-studio#install)를 보세요.

## GPU 사용 · GPU 대기 조건

Asset Studio는 생성, 태그 분석, 후처리, LoRA 학습, VLM 검수가 GPU를 동시에 쓰지 않도록 차례를
정합니다.

- **GPU 사용**: 지금 누가 GPU를 쓰는지 보여 줍니다. 외부 프로그램이 걸어 둔 예약은 **외부 예약
  해제**로 풀 수 있습니다.
- **GPU 대기 조건**: 작업 종류마다 남은 GPU 메모리가 얼마 이상일 때 시작할지, 어떤 프로그램이 켜져
  있으면 기다릴지 정합니다. 게임이나 다른 생성 도구를 함께 쓸 때 유용합니다.

## VLM 서버 · VLM 검증 (선택)

로컬 비전-언어 모델 서버(예: LM Studio)를 연결하면 생성된 이미지를 자동으로 검사해 참고 판정을
붙입니다. 기본은 꺼져 있습니다.

- **VLM 서버**: 서버 주소, 모델, 모델을 올리고 내리는 명령.
- **VLM 검증 사용**: 켜면 갤러리에 VLM 판정 표시가 나타납니다. **최대 자동 재생성 횟수**만큼 실패한
  이미지를 새 시드로 다시 생성합니다.
- 최종 판정은 언제나 사람이 합니다. VLM 판정은 참고용입니다.
