# 문제 해결

## ComfyUI에 연결할 수 없음

오른쪽 위 연결 표시가 빨간색이면 ComfyUI가 꺼져 있거나 주소가 다릅니다. ComfyUI를 켜고
**설정 › ComfyUI 연결 정보**의 주소를 확인하세요.

## 모델이나 노드가 "목록에 없음"

모델이나 커스텀 노드를 설치한 뒤에는 ComfyUI를 재시작하고 Asset Studio 페이지를 새로고침하세요.
이미지 도구는 필요한 노드가 없으면 그 이름을 알려 줍니다. 필요한 노드와 모델은
[README의 의존성](https://github.com/kiritype/asset-studio#dependencies)을 보세요.

## 대기열이 멈춤

작업이 실패하면 나머지 작업을 잃지 않도록 대기열이 일시정지합니다. 대기열 창에서 실패한 작업의
오류를 읽고 원인을 고친 뒤 다시 시작하세요.

## 생성이 시작되지 않고 기다림

다른 작업(LoRA 학습, VLM 검수)이 GPU를 쓰고 있거나 **GPU 대기 조건**에 걸린 경우입니다. 오른쪽 위
연결 표시와 **설정 › GPU 사용**에서 기다리는 이유를 볼 수 있습니다.

## LoRA를 켰더니 구도가 이상해짐

데이터셋이 작거나 한쪽으로 치우치면 LoRA가 구도까지 배웁니다(인물이 둘로 나오거나 지나치게
가까워지는 등). [LoRA 학습의 좋은 데이터셋](./lora#좋은-데이터셋)을 참고해 이미지를 늘리고, 강도를
낮추거나 이른 에폭을 써 보세요.

## 로그 파일

| 파일 | 내용 |
|---|---|
| `logs/studio.log` | 서버 |
| `logs/launcher.log` | 시작·종료 |
| `logs/lora/<학습 이름>/trainer.log` | LoRA 학습 |

## 내 데이터 백업

`data/`(라이브러리, 검수, 데이터셋, LoRA 기록, 설정)와 `outputs/`(이미지)를 백업하세요. 두 폴더는 git
저장소에 포함되지 않습니다.
