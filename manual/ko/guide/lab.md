# 생성·비교

**생성·비교** 화면은 프롬프트 라이브러리와 별도로 문장을 시험하고 결과를 비교하는 곳입니다. 주소는 기존과
같은 `/lab`입니다. 결과는 `outputs/_lab/<날짜>/`에 저장되고 갤러리에도 보입니다.

긍정·제외 프롬프트는 두 탭에서 함께 씁니다. 직접 입력할 수 있고, 태그 자동완성과 태그 확인 기능은
Danbooru에 없는 태그를 알려 줍니다. 생성 설정은 작업 화면과 같으며 프리셋을 불러오거나 저장할 수 있습니다.

## 단일 생성

**단일 생성** 탭에서는 프롬프트와 생성 설정으로 한 장만 만듭니다. **비교 생성** 탭에 입력한 값이나 작가 후보는
적용되지 않습니다.

## 비교 생성

**비교 생성** 탭은 같은 조건에서 시드만 바꾸거나, 한 가지 설정을 바꿔 결과를 나란히 비교합니다.

- **시드 비교**: 시드 수만큼 같은 프롬프트를 생성해 얼마나 안정적으로 나오는지 봅니다.
- **값 비교**: 한 항목의 값을 바꿔 봅니다.

| 항목              | 값 예                                                           |
| ----------------- | --------------------------------------------------------------- |
| CFG               | 3, 4.5, 6                                                       |
| Steps             | 20, 28, 36                                                      |
| 샘플러 · 스케줄러 | 비우면 목록 전체                                                |
| CLIP skip (SDXL)  | 1, 2                                                            |
| LoRA 강도         | 0.4, 0.7, 1.0                                                   |
| 작가              | 한 줄에 후보 하나. 여러 작가를 섞을 때는 한 줄에 함께 적습니다. |

작가 후보는 한 줄에 하나씩 적습니다. **작가가 없는 기준 결과 포함**을 켜면 작가 태그가 없는 기준도 생성합니다.
공통 프롬프트는 모든 후보에 그대로 들어가며, 이전 작가 태그를 자동으로 지우지는 않습니다. 후보마다 작가를
바꾸려면 공통 프롬프트에는 비교할 작가 태그를 넣지 마세요. 한 행의 모든 후보는 같은 시드로 생성됩니다.

한 번에 비교할 후보는 최대 12개, 시드는 최대 16개이며 전체 생성 수는 48장을 넘을 수 없습니다.

작업 미리보기나 갤러리 이미지, 이미지 도구의 프롬프트·분석 태그를 생성·비교 화면으로 보낼 수 있습니다.
다른 화면에서 가져온 경우 출처가 표시됩니다.

## 결과 비교

결과에서 두 장을 골라 **기준**과 **비교**로 놓습니다.

- **나란히**: 두 장을 옆에 놓습니다.
- **슬라이더**: 한 장 위에 다른 장을 겹치고 경계를 끌어 차이를 봅니다.
- **기준↔비교 바꾸기**, **비교 이미지 설정 불러오기**(마음에 든 쪽의 설정을 폼으로 가져옴)를 쓸 수 있습니다.
